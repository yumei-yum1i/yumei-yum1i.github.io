## 什么是逆向工程

逆向工程（Reverse Engineering）是指通过对一个已经存在的成品（如可执行文件、固件、APK 等）进行分析，还原其设计思路与实现逻辑的过程。在安全领域，逆向工程通常用于：

- **恶意软件分析**：分析病毒、木马、勒索软件的行为
- **漏洞挖掘**：定位程序中可利用的缺陷
- **软件破解**：绕过授权验证（仅限合法授权范围内）
- **协议逆向**：还原未公开的通信协议
- **竞赛与学习**：CTF 中的 Reverse 方向

## 逆向的两种视角

### 静态分析

不运行程序，直接阅读其静态内容：

- 查看字符串、导入表、资源
- 反汇编 / 反编译出伪代码
- 常用工具：Ghidra、IDA Pro、radare2

### 动态分析

实际运行程序，观察其运行时的行为：

- 单步调试、下断点、修改内存
- 监控系统调用与文件行为
- 常用工具：x64dbg、GDB、OllyDbg、Process Monitor

## 常用工具一览

| 工具 | 类型 | 说明 |
|------|------|------|
| Ghidra | 静态 | NSA 开源反编译器，免费且功能强大 |
| IDA Pro | 静态 | 工业级反汇编 / 反编译器 |
| x64dbg | 动态 | Windows 下强大的调试器 |
| GDB | 动态 | Linux 下经典调试器 |
| radare2 / cutter | 静态+动态 | 命令行逆向框架 |
| strings / binwalk | 辅助 | 提取字符串、分析固件 |

## 一个简单的分析流程

以分析一个 Windows 程序为例：

```text
1. 查看文件信息（file / Detect It Easy）
2. 查看字符串与导入表（strings / Ghidra）
3. 定位关键函数（入口点、main、可疑 API）
4. 反编译阅读伪代码
5. 动态调试验证逻辑
6. 必要时修改程序 / 编写补丁
```

## 如何系统学习

1. 掌握一门语言（C/C++ 有助于理解二进制、Python 辅助编写脚本）
2. 了解汇编语言基础（x86/x64）
3. 学习 PE/ELF 文件格式
4. 从 CTF 的 Reverse 题目入手练习
5. 深入操作系统底层（调用约定、堆栈布局）

> 逆向工程是攻击性与防御性安全研究的基础能力，请务必在合法授权范围内使用相关技术。
